# Reference run of 5 October 2026

These four result files, and the manifests that record how they were made,
come from the earlier run of the same scripts (scripts 13, 23 and 27) on a
Linux aarch64 machine with xgboost 3.2.0, shap 0.49.1 and scikit-learn 1.7.2.
The paper's numbers come from the final run of 11 to 13 October 2026 on
macOS arm64 with xgboost 3.0.2, shap 0.48.0 and scikit-learn 1.7.1.
Seeds and settings are identical in the two runs; only the library versions
differ. Script 34 compares the two and the paper reports the comparison.
